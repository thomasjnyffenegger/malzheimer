# Malzheimer

Website des Bierbrau-Vereins Malzheimer, Obfelden – [malzheimer.ch](https://malzheimer.ch)

Jedes Mal ein erstes Mal.

## Aufbau

- `index.html` – die ganze Seite (HTML, CSS und JavaScript in einer Datei)
- `fotos/` – Logo, Bier-Etiketten, Porträts und Fotos
- `malzheimer-hymne.mp3` – die Vereinshymne für den Abspielknopf

## Anpassen

Crew (Namen, Titel, Sprüche, Porträts) und Galerie stehen als Listen `CREW` und `FOTOS`
am Anfang des `<script>`-Blocks in `index.html`.

## Veröffentlichen

Alle Dateien unverändert ins Hauptverzeichnis des Webhostings legen. Es braucht keinen Build-Schritt.
